05 terms



  
酒館SILLYTAVERN

    
跟 AI 角色聊天、玩文字冒險的平台。聊天紀錄和角色都存在你自己的裝置上。

    
角色扮演多角色群聊自訂世界觀美化介面文字冒險

  
APIA·P·I

    
酒館只是一個「聊天室的外殼」，本身不會思考。真正會回你話的 AI 住在別人的伺服器上，像 Google 的 Gemini、DeepSeek、Claude、GPT 這些。

    
API 就像一張通行證＋一條電話線：你把它填進酒館，酒館就能打電話給那個 AI，把你說的話傳過去、再把 AI 的回覆拿回來。沒接 API，酒館就只是個不會回話的空房間。

    
API 可以去公益站拿（社群免費分享的），也可以自己花錢買。既然有免費的，那就用吧，免費的最香了。

    
公益站是別人架的，聊天內容會經過他們的伺服器，別聊真實個資；也可能隨時關閉。

  
預設PRESET

    
在後台操控 AI 怎麼寫的一組設定：控制角色的文風、字數、讓角色不像人機，還有狀態欄、小劇場這些花樣，也能讓角色解鎖成人內容（限成年人）。

    
同一張角色卡換個預設，感覺可能完全不一樣。

    
每個預設都有它適配的 AI（例如專門給 Gemini 或 Claude 用的）。接錯 AI 的話，預設可能會沒辦法正常運作，下載時看清楚作者寫的適用模型。

  
破甲JAILBREAK

    
AI 模型本身有內容限制，常常會拒絕或「出戲」。破甲就是預設裡讓 AI 放開限制、乖乖照角色設定演下去的那段提示詞。

    
效果看模型和預設，不同組合差很多。

  
角色卡CHARACTER CARD

    
存角色設定的檔案（通常是 PNG 圖片或 JSON），匯入酒館就能跟那個角色聊。可以去 DC 找，也可以自己寫。

Q&Atroubleshoot
08 items


Q.01卡在下載很久，或顯示失敗？
關掉視窗重跑一次就好，已下載的部分會自動略過。中國大陸請選「2 鏡像」，但酒館本體在 GitHub，需要能連上 GitHub。


Q.02打開沒畫面、手機一直轉圈圈？
1. 確認電腦的黑色視窗（或 Termux）還開著，酒館要一直開著才能用。
2. 用手機連的話，Tailscale 的開關要打開。它其實是一種 VPN，沒開就連不到你的電腦，會一直轉圈圈。


Q.03角色卡、聊天紀錄放在哪？
都在 SillyTavern\data。換電腦或重裝前把它複製出來就不會遺失。


Q.04手機連不上？
依序檢查：電腦的酒館開著嗎？兩邊 Tailscale 都開、同帳號嗎？跑過「開放手機連線.bat」嗎？防火牆按「允許」了嗎？


作者親身經歷我自己一開始也連不上，最後發現就是防火牆沒按允許。第一次啟動時跳出的「Windows 安全性警訊」被我關掉了，所以手機一直被擋在外面。


補救方法：

① 按「開始」，搜尋「允許應用程式通過 Windows 防火牆」並打開

② 按右上角「變更設定」

③ 在清單裡找到「Node.js JavaScript Runtime」（可能有好幾個，全部都要），把「私人」和「公用」都打勾

④ 找不到的話，按「允許其他應用程式」→「瀏覽」，選一鍵包資料夾裡的 runtime\node\node.exe

⑤ 按確定，重新雙擊「啟動酒館.bat」，再用手機開一次


想看更完整的圖文步驟，可以直接看老婆寶的 Windows 電腦本地部署：「進階一」教同一個 Wi-Fi 下用手機連電腦，「進階二」教用 Tailscale 出門連。


Q.05想重裝？
先備份 SillyTavern\data，刪掉 SillyTavern 資料夾，重新雙擊「一鍵安裝.bat」，再把 data 放回去。


Q.06裝好了，然後要怎麼聊天？
酒館只是「聊天的地方」，還要接上 AI 的 API 才能對話，角色卡也要另外找。這些一鍵包沒有包含，可以看 老婆寶的教程，或到 DC 社群 類腦、尾巴鎮 找。


Q.07AI 回覆跑超久？
接上 API 後多少會遇到小問題，最常見的是「跑很久」。大部分是因為 AI 的思維鏈太長，也就是它想太多了。可以考慮砍 token：例如原本設定輸出三千多 token，改成一千多。具體在哪裡改、怎麼調，可以把你的狀況拿去問 GPT 或 Claude，它們會一步一步告訴你。


Q.08全部試過還是不行？
可以找 Claude Code、DeepSeek Harness 這類能直接在電腦上幫你操作的 AI 工具，讓 AI 幫你處理，直接解放雙手，遠端也能叫它在電腦上搞定。也可以把黑色視窗的錯誤訊息截圖，拿去問 GPT 或 Claude。
